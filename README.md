This package contains preparation materials only. The 25 tracker entries are
unexecuted candidates, not confirmed defects.

## Included materials

- `candidate-defect-tracker.xlsx` — 25 requirement-based candidates, all marked
  **Not Executed – Verification Required** with actual results pending.
- `defect-summary.md` — candidate and verification counts.
- `defect-log.md` — three preliminary observations, with verification status
  retained for each.
- `defect-log-template.md` and `test-notes-template.md` — reporting templates.
- `evidence/` — supplied screenshots for preliminary checkout observations.
- `docs/`, `tests/`, and `performance/` — scaffolding only; no test suite or
  load test has been executed.
- `ai-sessions/` — AI-assistance disclosure summary; full sanitized exports
  still need to be added.

## Assessment requirements still outstanding

The candidate must author and own the final test design, execute and record
tests, add real evidence, complete automation/performance results, make a
release recommendation, and create the required five-minute recording. The
assignment prohibits AI agents from operating WholeCart. Do not report a
candidate as a defect unless an actual result differs from an approved
expectation and evidence is attached.

The tracker and supporting preparation materials are AI-assisted and must be
reviewed and disclosed. The test design must be the candidate's own.
